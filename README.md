# Karan Pulipati — Senior DevOps Engineer

10+ years in CI/CD automation, Kubernetes deployments, and release engineering. At Adeptia (2020–2026) I was the sole owner of the Jenkins CI/CD platform for 30 microservices, led its migration to GitHub Actions, and published each release to Artifact Hub and Docker Hub.

**Open to Senior DevOps roles — immediate joiner.**

---

## What I've Built

- **Chained Jenkins CI/CD platform** — CI → Master CD → QA Handoff across parallel 5.x and 4.x release tracks, cutting deployment turnaround from ~3 hours to under 1 hour
- **Reusable GitHub Actions workflow** — a centralized `ci-build.yaml` with automatic project-type detection, rolled out across 30 repositories
- **Release publishing** — versioned Helm charts on [Artifact Hub](https://artifacthub.io/packages/helm/adeptia-connect/adeptia-connect) and release-tagged images on [Docker Hub](https://hub.docker.com/u/adeptiainc)
- **Registry modernization** — 64 vendor JARs moved from Nexus to GitHub Packages; Docker images from Nexus to GHCR and Docker Hub
- **AKS operations** — namespaces, RBAC, ingress, Jenkins-driven Helm deployments, Prometheus and Grafana monitoring
- **CI/CD security** — GitHub App JWT authentication replacing long-lived PATs; SonarQube, Snyk, and Docker Scout scanning; SBOM attestations
